# 一条龙加密备份（butler-backup）

让 AI 助手把核心数据（记忆、身份与配置、用户交托的文件清单）的加密备份一次做完：助手自己装好校验过的 age 工具、自己生成密钥、打包加密并存放到用户选定的目的地、当场做一次恢复演练验过，最后只把私钥交给用户本人保存。用户不需要懂技术细节，也不需要先去另一台机器生成密钥。

核心纪律三条：没校验过的工具不用；恢复演练没通过不许说备份完成；私钥只亲手交给用户一次，助手自己不留副本。

## 文件

- `SKILL.md`：正文，完整流程与硬规矩。
- `skill.yaml`：技能描述文件（与 SKILL.md 配套，供 Muse 类平台识别）。

## 怎么用

把下面这段提示词发给你的 AI 助手，它会自己取回这份技能、装好并运行：

```
请打开这个仓库：https://github.com/irol765/butler-backup
读取其中的 SKILL.md 全文，把它保存为你的一个自定义技能（技能名 butler_backup，skill.yaml 一并保存）。然后按技能里的流程，替我把核心数据的加密备份做完：你自己生成密钥、当场做恢复演练，最后只把私钥交给我保存。做完用大白话告诉我：备份存在哪、演练过没过、私钥我该怎么保管。
```

如果你的助手无法访问外网，把 `SKILL.md` 的内容直接粘贴给它，效果相同。
